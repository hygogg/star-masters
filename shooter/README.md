# STAR MASTERS

enchant.js 製の 8bit 風・縦スクロールシューティング。
全3ステージ、各ステージの最後にボス。3体倒すとエンディング(スタッフロール)。

## 遊び方

ES Modules や fetch を使うため、ローカルサーバー経由で開く:

```sh
cd shooter
python3 -m http.server 8123
# → http://localhost:8123/ をブラウザで開く
```

| 操作 | キー |
|---|---|
| 移動 | 矢印キー / WASD |
| ショット | Z / Space(押しっぱなしで連射) |
| ポーズ | P |
| ミュート | M |

スマホ・タッチ操作にも対応(指の少し上に自機が追従、オート連射)。

- パワーアップ `P` を取ると最大3段階までショット強化(被弾で1段階ダウン)
- 残機3。ハイスコアは localStorage に保存
- タイトルで15秒操作しないとデモプレイ(STAGE 1〜3を自動プレイ)が始まる。キー/タップで即タイトルへ戻り、ハイスコアには影響しない

### 地上物

背景と一緒に流れる固定設置物。**通常ショットで空中物と同じように破壊できる**
(爆弾のような別武器は不要)。

- **砲台**(灰色・バレルが上向き) … 自機を狙って撃ってくる。200点
- **レーダー**(緑のディッシュ) … 撃ってこないが400点

### 中ボス

各ステージの中間で出現する。BGMが不穏な曲に変わり、コアが画面上部に降りてくる。

1. **4つのパーツが画面の四方(外)から飛び込んでくる** — 飛来中は当たり判定なし
2. コアの上下左右で**1秒静止** — ここから**パーツは無敵の障害物**になる
   (ショットを弾き、自機が触れると死ぬ)。コアへの攻撃もまだ効かない
3. パーツが動き出し、**1秒かけてコアと合体する**
4. **この1秒の間にコアへ14発当てて破壊すると 50000点 + ファンファーレ**
5. 合体してしまった場合は、動き回る中ボスに8発当てて破壊 — 1000点
   (**合体後はパーツの無敵が解除**され、どこに当ててもダメージになる)

合体するまでの間、**狙えるのはコアだけ**。パーツは撃っても壊れず、特に下側の
パーツがコアの中央を遮るので、真下から撃っていても1発も入らない。
※合体後もパーツが盾のままだと、コアの中央が完全に塞がって通常形態が
  事実上倒せなくなるため、合体と同時に無敵を解除している。

そのため後方から安全に撃つだけでは**最大11〜12発**しか入らず、14発には届かない。
**閉じてくるパーツの隙間に踏み込む**と当てられる数が一気に増える(最大22発)が、
下パーツの進路上に入ると接触で死ぬ。パワー1では上限9発なので、
ボーナスにはパワーアップが前提になる。

数値の根拠は [tools/measure_midboss.js](tools/measure_midboss.js) で実測できる:

```js
// index.html?debug=1 のコンソールで
console.table(measureMidBoss())
```

## ファイル構成

```
shooter/
├── index.html
├── lib/enchant.js        … enchant.js v0.8.3(公式ソースからビルド)
├── js/
│   ├── config.js         … ゲーム設定・全ステージ定義(敵の出現テーブル・ボス)
│   ├── assets.js         … アセットマニフェスト(画像/SE/BGM のパスを一元管理)
│   ├── audio.js          … BGM/SE 再生(Web Audio API、HTML5 Audio フォールバック)
│   ├── entities.js       … 自機・敵・ボス・弾・爆発・アイテム
│   ├── scenes.js         … タイトル/ステージ/ゲームオーバー/エンディング
│   └── main.js           … 起動・キー割り当て・デバッグフック
├── assets/
│   ├── img/*.png         … ドット絵(差し替え可)
│   ├── bgm/*.wav         … BGM 6曲(差し替え可)
│   └── se/*.wav          … 効果音 8種(差し替え可)
└── tools/
    ├── generate_images.py … ドット絵を再生成するスクリプト
    └── generate_audio.py  … BGM/SE を再生成するスクリプト
```

## アセットの差し替え方

画像・音はすべて `js/assets.js` のマニフェスト経由で参照している。

- **同じサイズの PNG / 任意の WAV に置き換えるだけ**でゲームコードの変更は不要
- パスやファイル名を変えたい場合も `js/assets.js` の該当行を書き換えるだけ
- 画像はコマを横に並べたスプライトシート。1コマのサイズ(fw/fh)とコマ数(frames)は
  `js/assets.js` に書いてあるとおりに合わせること
- 生成し直したいときは `python3 tools/generate_images.py` / `python3 tools/generate_audio.py`

## ゲーム調整

難易度・ステージ構成は `js/config.js` だけで完結:

- `STAGES[n].waves` … 敵の出現テーブル(出現時刻・種類・数・移動パターン・弾)
  - `pattern: 'ground'` が地上物(速度は背景スクロールに追従するので `speed` は未使用)
- `STAGES[n].midBossAt` … 中ボスが出現するフレーム
- `STAGES[n].boss` … ボスの HP・スコア
- `MIDBOSS` … 中ボスの猶予時間・パーツ位置・ボーナス点(1か所で完結)
- `PLAYER` … 自機速度・連射間隔・残機・当たり判定

## デバッグモード

`http://localhost:8123/?debug=1` で開くと:

| キー | 効果 |
|---|---|
| 1 / 2 / 3 | 各ステージへ即ジャンプ |
| N | 中ボスを即出現 |
| B | ボス戦へスキップ |
| K | ボス即撃破 |
| G | 無敵化 |

コンソールからも `__dbg.stage(0)` / `__dbg.midboss()` / `__dbg.boss()` / `__dbg.kill()` / `__dbg.god()` が使える。
